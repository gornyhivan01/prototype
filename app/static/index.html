Prototype

Учебный FastAPI-сервис: PostgreSQL, Alembic, SSO через Keycloak.

Войти через SSO

Откроется форма Keycloak — введите логин и пароль учётной записи реалма prototype. После входа откроется дашборд: обычному пользователю — профиль, администратору — управление пользователями.

Техническим путём

API и Swagger: /docs. Парольный вход: POST /auth/login — работает параллельно с SSO.
